# Inventario funcional KUQUBA

Ultima actualizacion: 2026-08-29

Este inventario separa la funcionalidad por audiencia principal: Huesped, Propietario y Ops KUQUBA. Tambien incluye una seccion transversal para capacidades compartidas de plataforma.

## Leyenda

- Implementado: existe UI/API conectada y persistencia o datos dev funcionales.
- Parcial: existe base visual, contrato tecnico o flujo dev, pero no cubre el proceso completo de negocio.
- Pendiente: aun no existe o depende de proveedor/decision externa.
